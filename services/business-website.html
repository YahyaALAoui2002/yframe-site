QUESTIONS

Common Questions About This Package

What if I need more than six pages?

Extra pages are quoted per page once we've scoped the full sitemap together, usually a modest add-on rather than a second project.

Do you write the copy for every page?

We sharpen and structure what you provide. Full copywriting across the site is available as an add-on if you'd rather we start from scratch.

Can I edit the site myself after launch?

Yes, if we set it up with a CMS. We'll flag which pages make sense to keep editable during the discovery call.

What if I only need design, or only need development?

Both are available as standalone services if you already have the other half in place, for example a finished Figma file that just needs building. Priced individually based on scope, get in touch and we'll quote it.
